# 抖音信号快照（选题信号，非事实证据）

这个目录是抖音热榜 / 对标账号的**离线快照**存放点。抖音信号默认关闭：
只有当本目录出现 `.json` 文件，或在 `.env.secrets.local` 配置了 `DOUYIN_API_KEY`
之后，`collect_douyin_sources` 才会把抖音标题作为热度排序信号并入现有流程。

> 关键边界：抖音标题只用于"选什么题 + 排序补盲"，**不充当事实证据**。
> 事实仍由现有的 RSS 候选 + 原站正文证据门冻结。这避免了直接搬运文案的
> 侵权/同质化风险。

## 快照格式

### 抖音热榜 `hotboard.json`

```json
{
  "captured_at": "2026-08-25T00:00:00+08:00",
  "items": [
    {"word": "标题", "hotScore": 1234567, "url": "https://www.douyin.com/..."},
    {"query": "标题", "heat_value": 987654}
  ]
}
```

### 对标账号最新视频 `benchmark_accounts.json`

```json
{
  "captured_at": "2026-08-25T00:00:00+08:00",
  "videos": [
    {"title": "视频标题/话题点", "account_name": "账号名", "play_count": 500000, "share_url": "https://www.douyin.com/video/..."}
  ]
}
```

## 怎么拿到数据（三条路，推荐中间那条）

1. **抖音开放平台官方热点接口**：稳定合规，需企业认证/申请权限。
2. **第三方数据平台（新榜/蝉妈妈/飞瓜）**：有热榜 + 达人视频数据 API，付费但稳定，导出成上面的 JSON 即可。
3. **爬虫**：不推荐——不稳定、违反平台规则、法律灰色（项目既有原则已明确不抓受限页）。

## 后续可选扩展

若要让"对标账号覆盖了、但 RSS 没抓到的选题"也能进入候选，可在快照里为视频
补充一个**原站正文链接**（`article_url`），并在 `collect_douyin_sources` 里把这
类条目转成候选交给证据门；当前版本只做热度排序信号，避免产生无法取证的空候选。
