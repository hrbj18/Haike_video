# 产品规则摘要

更新时间：2026-09-18

## 产品定位

OpenMontage 是“人审决策、机器执行”的视频生产工作台，不是逐帧手工剪辑器。用户提供或确认脚本、素材来源、风格、数字人、字幕与音乐；系统建立真实音频驱动的时间线并自动生成，用户在片段级审核、替换和热插拔。

## 核心不变量

- 音频时长是主时钟；画面跟随音频，禁止为了画面强行拉伸配音。
- 数字人素材与主体画面素材分层判断；有数字人不等于已有主体画面。
- 每个画面格独立编号、锁定、替换和重做；局部修改不影响已冻结片段。
- 片段预览与全片渲染共享同一字幕、数字人几何和素材时间线合同。
- 异步任务必须有明确的开始、进度、当前项、失败原因和恢复操作。
- 所有用户提示使用中文；底层异常映射为可操作的中文说明。
- 正式发布始终需要人工确认。

## 默认生产规则

- 当前主工作流：双角色数字人口播 + 网络视频/HyperFrames 主体画面。
- 默认画幅：9:16、1080×1920。
- 主体画面优先动态素材；静态图片默认关闭。
- 短视频实拍素材约每3秒切换一次，允许为消除碎尾在2.2—3.5秒内均衡；HyperFrames单个连续画面不得超过5秒。台词句子是语义单位，不是画面槽边界，长句必须继续拆镜。
- 同一网络素材在一条成片中只能使用一次；以供应商素材ID优先、来源URL次之、项目资产ID兜底判重。裁切、改名或复制文件不能规避判重。
- 字幕逐句显示，可保存软件级默认样式。**面向竖屏平台发布的成片，字幕底边必须高于画面高的 0.80**（平台底部作者/描述/话题块会覆盖该线以下）；字号上限取「最长句不溢出画布」，不得靠自动换行兜底（渲染层 `WrapStyle:2` 不折行，超宽直接裁边）。
  ★ **断行必须落在词与词之间**：行宽是算术，按「第 N 个字符」切的硬上限会把 `1000` 切成 `100`+`0`（成片里真的出现过以孤立 `0` 开头的字幕）。ASCII 字母/数字串（`1000`、`Model 3`、`7:14`、`48%`、`UnifoLM-WLA-1.0`）视为不可断整体；串在行首时允许超预算，上限 2× 预算（拉丁字符宽约为汉字一半）。
- 手工工作台调整背景音乐时，先做单片段音量样板再应用全片；有数字人一键路线则在最前面的付费确认中同时冻结人声、音乐、区间和增益，正常执行中不得在配音后重复打断。
- **二次精剪的相邻对话间隙**：`pause_target_gap_seconds` 是**成片里相邻两句之间实际保留的间隙**（v7 起；`keep = max(guard, gap/2)`，guard 只作下限不再叠加），默认 **0.3 秒**。
  间隙压缩范围默认 `gap_policy=any`（**连环境音一起压**，VAD 间隙直接作候选，不需要静音证据）；
  想要旧的"三重许可"（必须被 `silencedetect`/包络判为静音）就切到 `quiet`。
  **`any` 会删掉真实存在的环境音**（实测某素材 10 处 / 9.09 秒间隙电平 −18…−29 dB，
  是电机与人群），所以每一刀的 `reason` 都要标注"该段不是静音"，并在界面保留一键切回 `quiet`。
  字幕是**审看工具**：交付时提供**无字幕成片**（同一计划关掉 `burn_subtitles` 另渲一份，
  绝不覆盖已审看的预览）+ **输出时间轴的 SRT**。
- **软件级响度默认（2026-09-16 修订）**：人声 **+8 dB** / BGM **−6 dB** / 成片目标 **−9 LUFS**（各期按母版峰值单独下调，可为 −10.5 / −12）；验收 `|I − target| ≤ 1.5` 且 `TP ≤ −1.0`，正式渲染不达标**直接 raise**（预览只告警）。唯一真源头是 `narration/music/output_loudness_preferences.py` 的三个 `DEFAULT_*` ＋落盘 `.backlot/*_preferences.json`；批次脚本与 spec 生成器不得再各存一份默认值。★ 响度有物理天花板：收尾 `loudnorm linear=true` 是单增益，`I = min(目标, −2.0 − 波峰因数)`，**抬人声增益抬不动它** ⇒ 母版偏轻的期必须单独下调目标值。★ **抬 BGM 会推高波峰因数 ⇒ 天花板下降**，贴边期必须同步下调该期 `target_lufs` 并带上 `music` 步重跑。
- **BGM 必须能透过人声（2026-09-16）**：混音人声/BGM 差控制到 **≤4~5 dB**；验收只看音频包络的 **P5/P25**（对白间隙处 BGM 唯一露头的位置），**不得用整片 200–800 Hz 的 LUFS**（该带由人声主导，正确改动会被误判 FAIL）。
- **口播处理链（2026-09-15）**：人声增益不再只做 `volume=NdB`，改为 `highpass 90 → EQ 3k +3dB → volume(增益+10) → alimiter 0.85`。裸增益会把台词推到 +0.6~+2.9 dBFS 削顶（既失真又不清晰）；驱动进限幅器才能把波峰因数 13.2 压到 9.4，这是可达响度 +1.8 dB 的来源。驱动量上限由 `TP ≤ −1.0` 反推（+22 dB 即越线）。★ 用户可见的 `playback_gain_db` **不等于**中间产物的实测增量；中间态电平不得单独按发布容差否决（混音前掐死整条链）。
- **外站素材复刻（2026-09-17）**：素材选择权归**本项目**，不归 copyskill —— 其产出只是素材池的一份输入，与 Pexels 地位平等；选区段前必须先看多宫格帧大图，禁止「整条源当一整块素材」。机读契约是 `schemas/remake-spec-v1.json`，帧口径与 `_validated_visual_timeline` 一致。
- **重建项目必须保留两条音频默认（2026-09-16）**：`remake_build_project.py` 从 spec 取增益时**缺键必须兜底软件级默认**（人声 +8 / BGM −6），不得写 0 —— 原实现的人声一侧会把口播增益静默写成 0 dB（预览能过、上手机才发现发闷）。spec 生成器应显式写 `narration_gain_db`，不得依赖历史 spec 旧值。
- **竖屏平台音频不变量**：抖音回放**不做大幅整体衰减**（实测全频仅 −1.1 dB），但**专门削低电平内容**（P5 −4.4 / P25 −4.3 dB）；叠加手机单扬声器 **<300 Hz 衰减 15~20 dB** ⇒ BGM 低频在手机端消失。**抬 BGM 是唯一有效杠杆**，下调 `target_lufs` 只会让整条更小、不会让 BGM 变清楚。音频结论必须来自**平台实测**（`share-download` 取回 + 分带/包络 + 本地 53 kbps AAC 对照组），不采信本地听感推测。
- **顶部文字图层与署名牌**：一层只有一种颜色（双色标题＝两层）；**不自动换行，超框裁字**（内容区 492px，10 汉字行 ≤48 号），换文案必须重测。多期共用钩子时字号按整体等比缩放锁定，**逐行各自取最大号会让短行飙号**。署名牌落在数字人圆框正下方圈外，多期一致。
- 云端付费任务必须幂等、可恢复、可审计，并受项目预算约束。
- 云端付费产物（数字人、配音）的复用记录只与**当次任务**绑定：新起同种任务会重新提交并重新扣费。仅因本地改动而要重出预览时，必须走 `full_preview`（纯本地合成），不得新起付费任务。
- 已注册的一键审核预览和全片预览必须经统一生产队列取得跨项目执行资格；网页、Codex、定时与恢复来源共享同一优先级/FIFO规则。新高优先级不强行中断已开始任务，`ambiguous` 必须先人工核对，队列终点仍为待审预览。

## 前端职责

- 项目库：创建、删除、自动化总开关和最近运行状态。新建入口只选择“无数字人口播 / 有数字人口播”、项目身份和画幅；时长、内容目标、视觉风格及数字人细节延后到对应工作台。
- 新项目脚本入口：只展示“视频标题”和“输入脚本/简单想法”两个文本输入；标题默认继承项目名。用户选择“整理已有脚本 / 扩写简单想法 / 从零生成脚本”后，由项目内置大模型按对应语义生成草案，输入先持久化，草案仍须人工审核。
- 总览：从脚本到待审预览的阶段进度、阻塞、预算和下一步。
- 数字人素材：角色、脚本、音频、长视频生成/导入、ASR 与切割。
- 片段工作台：主体画面、数字人样式、字幕、音乐试听和局部热插拔。
- 素材库：引用关系、重复检测、未使用素材清理和来源追踪。
- 成片与版本：全片预览、QA、版本差异和人工发布。
