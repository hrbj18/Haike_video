## 二次精剪 V3 与第一步粗剪推荐层（2026-09-11 已完成）

指导文档：`docs/SINGLE_DEVELOPMENT_GUIDE_INTERACTION_PAUSE_RECOMMEND_V3_ZH-CN.md`（含完整验收结果）。

**停顿压缩落地**。此前「减少对话中间停顿」两端都没实现：`_group_ranges` 用首末分句包络整段取出，
`_pause_removals` 只看句间空隙，`pause_windows` 又只是模型用不上的装饰证据。V3 把它做成计划层的
一等派生数据 `pause_trims`，需要**三重许可**同时成立：不得与 VAD 语音帧相交（词级保护）、
`silencedetect` 判定为静音（防笑声/环境音被当死气）、单条足够长；两侧各留 0.12s guard，
保留 0.2s 呼吸。渲染层零改动 —— 它本来就支持任意多段 concat。

真实 25 条候选实测：**删减 81.0s（5.5%），143 刀，与 VAD 语音帧相交 0 次，22/25 条有削减**。
全程端到端（R0007：143.6s → 53.7s）QA 通过、字幕 16 句烧入、零降级；成品回听校验显示语音未丢失。

**渲染走审核代理**。`render_second_pass_candidate` 原先直读原片，长 HEVC 时间戳断裂的缺陷完整存在；
现与候选渲染同构（`source` 管指纹与契约，`render_source` 管取帧）。

**字幕烧入**。`subtitle_cues` 原先只进签名与界面列表。现按输出时间轴生成 SRT 并以 `subtitles` 滤镜烧入，
且**先用半秒窗口对照抽帧自证**（libass 真出像素才继续）；失败必须落 `degradations` 并出无字幕版本。
Windows 上滤镜值必须整体单引号包裹，否则驱动器盘符的转义冒号会被当成 `original_size`。

**多段切割的画面掉队缺陷**。每段 `trim` 是帧对齐、丢不足一帧的余数，音频按采样对齐不失真；
1–2 段时误差在容差内，**压缩 13 处停顿后累积 0.322s**并被 `audio_video_tail` 正确拒绝。
修法：`fps` 之后 `tpad=stop_mode=clone:stop=-1` 再 `trim=duration=`，让画面覆盖音频。渲染版本升 v2
（签名含版本，否则旧 v1 预览会被误判命中）。

**第一步粗剪推荐层**。原评分只有 `engagement/visual_clarity/story_value`，产品四条标准一条都没实现。
新增 `material_interaction_recommend.py`：同一主体（时长主导 + 描述一致性 + 完整性）、高情绪、
讲外语、歌舞或互动效果好，四项加权 + **中文理由 + 证据片段**，输出旁路 `recommendations.json`
（**不改索引签名，因此不可能触发 34 次视觉重复付费**）。28 条事件 100% 可解释，与原分相关系数 0.540。
两个实测局限已写进模块文档：本素材 27 组/28 事件，故"同一主体"主要表达时长而非跨窗归并；
本素材无唱歌跳舞，标准 4 由其自身兜底条款（合影/比心/握手）生效。

**依赖自检**。`_second_pass_preflight` 原先只问文本模型是否配置，缺 VAD 运行库/代理/FFmpeg 要到
渲染才暴露。新增 `_interaction_dependency_preflight`：逐项给 `{ok, label, remediation}`，
**读路径刷新、变更路径只读快照** —— 诊断信息不得让"确认入库"这类原本不需要 FFmpeg 的路径产生新依赖。

**仍未验（不得由本次结论替代）**：真实模型的逐切口听辨、1.1/1.25 倍速听感、第二主体、独立素材、
Linux 预发布。本次只覆盖 `local-material-understanding-test` 的 R0007 一条完整链路。

## 二次精剪 V4：短语级语音单元 + 权重排序（2026-09-12 已完成）

指导文档：`docs/SINGLE_DEVELOPMENT_GUIDE_INTERACTION_PHRASE_UNIT_RANK_V4_ZH-CN.md`
（§12 含完整 A/B/C/D 实测与 12 条实施中发现的缺陷）。

**根因只有一个**：腾讯 ASR 在长素材上只有 **60 秒级分块**（实测 60.26 / 27.40 / 60.48 / 60.04 /
60.02 / 46.45 秒）。它同时解释了用户的四条抱怨：掐头去尾只剩整块粒度、跨界的 `U00001` 被
`_containing_range()` **整条静默剔除**（前 48 秒从未进入模型视野）、3–5 秒精彩前置物理上构造不出来
（实测 `hook_candidates=[]`）、停顿压缩的每刀固定开销超过素材 0.45–0.60 秒的对话间隙。

**短语级语音单元**（`backlot/material_interaction_units.py`）：以 VAD 语音块为原子，短语流按字数
单调投影上去，得到 2–6 秒单元 `P0001…`。**单元边界永远落在 VAD 间隙里** —— 截词在结构上不可能
（实测 38 个单元、边界违规 0）。分句与语音块只做交集不做搬运；**无文本的单元强制保留**
（`spoken_units_partial_text` 显式降级）；没有语音证据就退回分块级并写明原因。
计划升 **v6** 冻结 `spoken_units`；字幕仍按原始 ASR 分句生成（`_caption_utterance_ids()` 桥接两个 id 空间）。

**首尾锚定是确定性词表**（`material_interaction_story._anchor_edges`）：第一个命中开场词表的单元当片头、
最后一个命中告别词表的单元当片尾，区间外的组整组 drop、两个锚点所在组**强制保留**；
跑在 `_dependency_closure()` **之后**并剥掉指向被裁组的 `depends_on`。
★ 词表按 **ASR 短语**匹配（整词/多一字/重复字/语气词），否则"你好聪明"会被当成开场词
——真机验收时它把前 32 秒整段裁掉。`trim_head/trim_tail` 不再强制删模型主张保留的开场组。

**目标时长按素材比例**：`duration_policy=proportional`（0.70–1.00×父内容，夹到 15–1800 秒）；
只在调用方**没写** `target_min/max` 时才默认，否则显式秒数会被静默覆盖。提示词同步去掉"凑时长"措辞。

**停顿压缩两层联动**：`pause_preset`（conservative / standard / **tight 默认**）同时决定探测
`min_silence` 与计划层 `guard/gap/min`；显式数值优先于预设。实测同一父范围（136.5 秒）
`conservative` 6 刀/2.84 秒 → `tight` **23 刀/6.90 秒**，与 VAD 相交仍为 0。

**推荐层 v2**：计分因子 `duration / foreign_speech / high_emotion / performance`，默认权重
**40/25/20/15**（时长 > 老外 > 情绪 > 互动/歌舞）；**同一主体降级为选材要求**（不进综合分）；
`ORDER_MODES` 默认 `duration_desc`＝优先时间长；`rank_events()` 是唯一定序实现；
读接口 `GET .../interactions?order_mode=&w=`（具名权重），**覆盖请求只内存重算不写缓存**，
v1 缓存自动免费重建。界面改**左素材（sticky 播放器）/ 右评分**双列 + 权重面板。

**长视频测试2 端到端**（5333.03 秒 / HEVC 912×1920 / 1.72 GB）：
27 条事件，默认「优先时间长」；前 3 名中 **#1（202.0 秒）超出首次切片 180 秒合同被跳过并记录**，
实做 #2/#3/#4 三条二次精剪：**149.637→118.153**（压缩停顿 10.184 秒/30 刀，`within_target`）、
**135.998→112.696**、**137.735→77.716**，三条 `qa`/`content_qa` 全通过，预览 118.167/112.708/77.716 秒。
**对照改前**：同一条 R0007 通道 v5 是 136.527→53.593 秒（内容删减 75.897 秒），
v6 是 149.637→118.153 秒（模型主动删除的语义组只占 6.3 %）。

**仍未验**：真实模型选段的逐切口听辨、1.1/1.25 倍速听感、第二主体、独立素材、Linux 预发布。
排序按时长优先与"单个互动 ≤180 秒"的首次切片合同之间存在真实冲突（#1 被跳过），记录待产品决策。

## 素材证据层 V1（2026-09-12 已完成）

指导文档：`docs/SINGLE_DEVELOPMENT_GUIDE_MATERIAL_EVIDENCE_LAYER_V1_ZH-CN.md`（§12 含完整 A/B/C/D 实测与缺口）。

把分析文档的 P0-A/B/C 做成**可复用素材证据文档** `material-evidence/<签名>/{evidence.json,envelope.npz,motion.npz}`：
分区独立降级（`status=available|partial|unavailable` + 中文 `degradations[]`）；签名**只含身份**，
`threshold_db` / `min_silence_seconds` 刻意不进签名 —— 改阈值是纯派生视图。**索引签名未变，34 个视觉窗口未重复计费。**

**音频**：一次 `ffmpeg -vn -ac 1 -ar 16000 -f s16le pipe:1` 换全片 20ms 窗/10ms hop 的 RMS 包络，静音判定降为内存函数。
**标定教训**：numpy 单声道 RMS 与 `silencedetect` **不同名** —— 名义 −30dB 会多判 **2.49×** 静音、**1.76×** 删减；
标定工作点是 **−40dB**（删减 80.5s/138 刀 vs 基准 81.0s/143 刀，0.994×/0.965×，均值 IoU 0.881）。
**运动**：全片 96×54 灰度 @2fps 一次解码成时间线（10665 点）；旧"每窗 `-ss`"采样把 2fps 网格锚在窗口起点，
与全片网格**相位本就不同**（实测 δ 最大 2.116e-1），故等价性判据是**决策等价**（同源实时对照 12/12 一致），
不是数值位相等 —— 这条已按"修正口径而非降低标准"写进 §12.6。

真实验收（S-001）：音频 spawn 27→**1**、运动 spawn 12→**1**、单轮墙钟 3.8s；7 组阈值复算 **6.4ms/组、0 spawn**
（旧 189 spawns ≈ 15.6s）；剪辑窗口 ∩ VAD = **0**；物证覆盖 **24s → 5333s**。
**缺口如实记录**：事件覆盖率 **8/28**（旧 3/28）—— 28 个事件只有 23 个内部含 ASR 间隙、其中仅 8 个有
≥0.5s+padding 的不重叠间隙，故 **28/28 物理不可达**（上限 23/28）。提升方向是补 ASR 分句粒度，不是放宽证据层。

副作用：`material-pause-evidence` 身份新增 `backend/engine/detector`、`interaction-pause-visual` 升 **v2**
（并入 `motion_identity`；`max_windows` 刻意不入签，使"只换运动来源"不作废逐窗冻结结果）
→ 两类旧缓存**各一次性失效重算**，旧文件仍可读。
