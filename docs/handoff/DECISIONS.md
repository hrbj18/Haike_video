# 当前有效决策

更新时间：2026-09-01

## 生产与调度

- 一条龙流程由 Haike Video 工作台和后台任务系统调度；Codex负责开发、诊断和测试，不作为唯一生产者。
- 每日窗口为北京时间上一自然日 00:00—24:00，计划时间为凌晨 03:00。
- 自动流程只产出待审核预览，不自动发布。
- 本地配音由 Haike Video 自带 Qwen3-TTS localhost 服务负责，不再启动或依赖独立 Voicebox。上层 `VoiceboxTTS` 类名、`voicebox_tts` source_tool 和历史资产目录暂时保留为兼容标识，不代表外部运行依赖。
- 重型 TTS 依赖与主环境隔离；模型和私有克隆音色不进 Git。公开仓库提供三种中文预设，雅雅/檬檬通过私有音色包跨机器迁移。默认只驻留一个1.7B模型，全部本地生成串行执行。
- Windows计划任务每日03:00启动，启用 `WakeToRun`、`StartWhenAvailable`、`IgnoreNew` 和12小时上限。2026-08-29 03:20设一次性Codex守护，固定检查2026-08-28目标日期；只从安全阶段幂等恢复，不重复启动或重提未知付费任务。

## 新闻与脚本

- 选题数量由当天价值和证据容量决定，常规为 3—4 条；9 个有效信息单元只是 90 秒规划目标，不是停机门。强候选不足时允许自然缩短，禁止用低价值新闻或重复台词凑时长。
- 排序优先考虑：中国互联网讨论热度、国际前沿价值、国内外大厂动作、模型/芯片/机器人/生命科学等长期影响、事实可靠性和画面表达价值。
- 手机配置、消费品小改款和缺少产业意义的花边消息降权。
- 生产使用 H/C/U 和冻结 claim 分配台词槽，不再用 S/A/B 或固定句数控制篇幅。
- 全片相邻台词必须换角色，任一主播字数不得低于30%；相邻句必须切换信息维度。
- 第一行固定以“每日科技快讯来了”保留栏目身份并直接进入具体钩子。85分优质稿标记 `auto_release`；78—84分或高级单项未达优质线、但结构/事实及可靠最低单项均通过的稿件标记 `fallback_review_candidate`，可继续生成醒目标记的待审视频。低于78分或命中事实、结构、预算红线仍阻断；任何等级都不得自动发布。
- 每句必须适合口播和字幕，避免旧脚本 T2/T22 式超长句。
- 豆包（火山方舟，OpenAI 兼容，`DOUBAO_API_KEY`/`DOUBAO_BASE_URL`/`DOUBAO_TEXT_MODEL`）担任每日快报中国市场主编，负责候选市场评分、中文台词和独立新请求冷审；主模型 `gpt-5.6-luna` 只做事实技术兜底及豆包不可用时的可审计降级。豆包有效返回的市场判断或打回不得交给 Luna 覆盖。事件聚类、证据/风险门、冻结 claim、结构与标题事实边界仍由代码决定；产物记录 selection/writer/reviewer provider、model、降级原因、prompt 版本与样稿指纹。
- 黄金范例库 `backlot/golden_scripts/` 只加载用户明确批准的样稿；注入 prompt 前匿名化公司、型号和数字，通用种子或损坏样稿不得进入生产。
- 抖音热榜/对标账号仅作非致命选题信号：优先请求配置的 HTTPS Bearer JSON API，失败回落 `config/douyin_snapshots/` 快照；状态区分 `api/snapshot/skipped/failed`。标题只用于排序补盲，不充当事实证据。
- 文本韧性已实现整期组合评分、有界恢复、相同拒稿抑制、新鲜写稿、下一组合和可靠线候选放行；可确定元数据修复必须证明台词SHA256不变。

## 数字人与云端费用

- 每位角色使用一段纯净长音频和一段长数字人视频，完成后按逐句时间切割；不逐句调用云端模型。
- 正式数字人默认使用已付费验收的 RunningHub 工作流 `2094449979141218305`、配置档 `infinitetalk_448x560_exact_clock_v2`、冻结模板 `config/runninghub/workflow-2094449979141218305.api.json`。角色音频计划完成后，只对最终实际上传的 PCM16 mono WAV 做一次25FPS帧对齐，并将总帧数提交给节点35；不得逐句向上取整再累加。
- 正式生产默认显式请求 Standard 24GB（`instanceType=default`）；不再追求 Lite。Plus 48GB 绝非全局默认：只有用户在当前父任务的唯一前置确认中显式授权并冻结 `plus_48gb_authorized=true`，同一角色前两次均为明确终态 OOM，且第 3 次提交前预算复核通过，才允许使用一次 Plus。直接 API 或其他任务未显式授权时默认 `false`；未知、非 OOM 或产物合同失败绝不升级。
- 角色级自动恢复固定为 `default → default → conditional plus`，两位角色严格串行，每位最多 3 次且永久禁止第 4 次自动提交。每次新提交前重新检查预算；已完成角色、配音、有效文件和已结算任务全部复用。已有 task ID 只轮询或对账；提交/查询结果不明进入 `ambiguous` 并停止，不得创建替代付费任务。
- V2 精确帧清单是逐句切点权威，Whisper 仅作自动诊断，低置信度或 ASR 失败不得开启二次人工切点审核，也不得改写确定性切点；只有清单、输入或外部产物漂移才停止任务。
- 供应商视频的帧数/时长漂移不是 OOM。仅当 V2 manifest SHA、输入签名和角色音频账本匹配，原片 PTS 从 0 按 1/25 秒连续，缺失不超过 5 个末尾帧，且被克隆帧起点至冻结 PCM16 WAV 结尾全部为零并位于最后语音之后时，允许本地克隆末帧并以冻结 WAV 为唯一音源重新编码封装。必须保留带 SHA 身份的 provider raw；本地规范化不得增加尝试、预算预留、上传或付费提交。
- 2026-08-27 双角色已用该配置完成实测并获人工认可：檬檬0.455元、雅雅0.775元，账单折算约4元/小时，总费用1.23元。
- 2026-09-01 精确帧工作流以 Standard 24GB 完成短样本付费验收：任务 `2094459897784782850`，输入113,280采样/118帧/4.720秒，输出视频118帧/4.720秒且音轨4.720秒，消费0.176元；旧工作流仅保留兼容和历史诊断。
- 每日总预算不超过 5 元；任何实际费率异常必须停止后续付费提交并展示证据。
- 4:5 数字人不得拉伸；圆形模式先做方形取景再加圆形蒙版，预览与渲染必须一致。
- RunningHub 上传工作流文件名不得超过50个字符；后续交付使用用户指定的中文工作流名，并在构建与测试阶段阻断超长名称。
- 旧 LongCat 与早期 InfiniteTalk 256×320、384×480配置只保留兼容和诊断用途，不再作为每日快报默认生产路径。
- 新默认工作流输出448×560、25FPS，接受4:5半身近景与长音频；每位角色仍只提交一次长音频，再按逐句时间线切割复用。

## 画面与审核

- AI 画面规划器在网络视频和 HyperFrames 之间按时长控制比例，默认实拍 60%—70%、HyperFrames 30%—40%，静态图片默认不用。
- 视觉批次失败时只恢复失败槽位，已完成素材不得重做；HyperFrames布局检查失败可回退未使用的网络素材。为修复最终比例，可在两轮严格语义审查后启用显式 `contextual_broll`，只允许相关、非误导、全片唯一的环境补画面，并记录拒绝理由与策略覆盖。
- 官方素材提取已启用：证据抓取时从原站正文抓 `og:image`（回退 `twitter:image`/首图）作为官方配图，标注 `license="press"` 与署名来源，沿 research→selection→script→scene 透传；AI 导演在图片槽位优先下载官方配图（下载/筛查失败自动回落 Pexels），资产标记 provider=`官方媒体`、保留 `attribution`。仅图片槽位生效，视频槽位仍走 Pexels/HyperFrames。无需 API key，仅复用现有原站正文 HTTP 抓取。
- 每条新闻以 `story_id` 复用右上角固定小标题；HyperFrames 不得重复烘焙该标题。成片目标 -14 LUFS，并由交付门禁复测。
- 人物台词增益和背景音乐增益是两个独立项目合同；处理顺序固定为人物增益、背景音乐、最终 loudnorm。新项目本机人物默认值为 +3 dB，历史项目不追溯改写；任一声音设置变化都必须重新生成并确认第一段声音样板。
- 已锁定格不会被批量操作覆盖；单格替换不得影响其他格。
- 先快速生成全片预览，再回到问题片段做局部返工。
- 片段工作台中的数字人取景编辑器只显示静态、强制静音的预览帧；进入页面、刷新、切换片段或控件重绘都不得自动播放或恢复原声音频。
- 新项目默认使用左上圆形数字人模板：位置 `x=0.04 / y=0.03`、宽度 `0.29`、底部裁切 `0`，圆形取景 `x=0.48 / y=0.38 / zoom=1.15`；这是 2026-08-23 项目人工调整并应用全部 15 段后的确认值。
