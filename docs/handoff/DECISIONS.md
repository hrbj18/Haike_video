# 当前有效决策

更新时间：2026-09-18

## 生产与调度

- 生产由 OpenMontage 工作台与后台任务系统调度；开发方只做开发、诊断、测试，不作为唯一生产者。
- 2026-09-08 起，无/有数字人一键审核预览与全片预览由 SQLite 统一生产队列串行调度；工作台与开发方只是提交来源。队列不执行任意命令、不扩大费用授权、不自动批准或发布；提交来源不天然获得更高优先级。
- 每日窗口为北京时间上一自然日 00:00—24:00，计划时间为凌晨 03:00。
- 自动流程只产出待审核预览，不自动发布。
- 本地配音由自带 Qwen3-TTS localhost 服务负责；`VoiceboxTTS` 类名、`voicebox_tts` source_tool 与历史资产目录仅为兼容标识，非外部依赖。
- **端口 `127.0.0.1:17494` 就是内置 Qwen3-TTS 服务，不是 Voicebox**；`TTSServiceUnavailable http://127.0.0.1:17494` ＝ 内置配音没在跑，非「第三方组件缺失」。装/启见 `scripts/setup_local_tts.ps1`、`scripts/start_local_tts.ps1`。
- **当前生产配音统一走云端**（`doubao` / `tencent`）；本地服务只是兼容与离线路径。服务未启动时 `VoiceboxTTS.get_status()` 返回不可用、`audio_center._local_profiles()` 返回空列表**且不发网络请求**，是优雅降级不是故障。
- 因此**强制本地 provider 为"可用"的测试必须同时把音色目录打桩**（见 `tests/backlot/conftest.py::local_tts_catalog`）：`get_status()` 改成可用后 `list_profiles()` 会产生真实 HTTP 调用，用例即隐性依赖后台服务。
- 重型 TTS 依赖与主环境隔离；模型和私有克隆音色不进 Git。公开仓库提供三种中文预设，雅雅/檬檬通过私有音色包跨机器迁移。默认只驻留一个 1.7B 模型、本地生成全串行。
- Windows计划任务每日03:00启动，启用 `WakeToRun`、`StartWhenAvailable`、`IgnoreNew` 和12小时上限；恢复只从安全阶段幂等进行，不重复启动或重提未知付费任务。

## 新闻与脚本

- 选题数由当天价值和证据容量决定，常规 3—4 条；9 个有效信息单元只是 90 秒规划目标，不是停机门。强候选不足时允许自然缩短，禁止用低价值新闻或重复台词凑时长。
- 排序优先：中国互联网讨论热度、国际前沿价值、国内外大厂动作、模型/芯片/机器人/生命科学等长期影响、事实可靠性与画面价值。
- 手机配置、消费品小改款与无产业意义的花边消息降权。
- 生产用 H/C/U 与冻结 claim 分配台词槽，不再用 S/A/B 或固定句数控制篇幅。
- 全片相邻台词必须换角色，任一主播字数不得低于30%；相邻句必须切换信息维度。
- 第一行固定以“每日科技快讯来了”保留栏目身份并直接进入钩子。85分优质稿标记 `auto_release`；78—84分或高级单项未达优质线、但结构/事实/可靠最低单项均通过者标记 `fallback_review_candidate`，可继续生成醒目标记待审视频。低于78分或命中事实、结构、预算红线仍阻断；任何等级都不得自动发布。
- 每句须适合口播和字幕，避免旧脚本 T2/T22 式超长句。
- 豆包（火山方舟，OpenAI 兼容，`DOUBAO_API_KEY`/`DOUBAO_BASE_URL`/`DOUBAO_TEXT_MODEL`）是每日快报中国市场主编：候选市场评分、中文台词与新请求冷审。`gpt-5.6-luna` 只做事实技术兜底与豆包不可用时的可审计降级，不得覆盖豆包的判断或打回。事件聚类、证据/风险门、冻结 claim、结构与标题事实边界仍由代码决定；产物记录 selection/writer/reviewer 的 provider/model/降级原因/prompt 版本与样稿指纹。
- 黄金范例库 `backlot/golden_scripts/` 只加载用户明确批准的样稿；注入 prompt 前匿名化公司、型号与数字，通用种子或损坏样稿不得进入生产。
- 抖音热榜/对标账号仅作非致命选题信号：优先请求配置的 HTTPS Bearer JSON API，失败回落 `config/douyin_snapshots/` 快照；状态分 `api/snapshot/skipped/failed`。标题只用于排序补盲，不作事实证据。
- 文本韧性已实现整期组合评分、有界恢复、相同拒稿抑制、新鲜写稿、下一组合与可靠线候选放行；可确定元数据修复须证明台词SHA256不变。

## 数字人与云端费用

- 每位角色用一段纯净长音频与长数字人视频，完成后按逐句时间切割；不逐句调用云端模型。
- 正式数字人默认用已付费验收的 RunningHub 工作流 `2094449979141218305`、配置档 `infinitetalk_448x560_exact_clock_v2`、冻结模板 `config/runninghub/workflow-2094449979141218305.api.json`。角色音频完成后，只对最终上传的 PCM16 mono WAV 做一次25FPS帧对齐，总帧数提交给节点35；不得逐句向上取整再累加。
- 2026-09-08 起新正式生产默认 Plus 48GB（`instanceType=plus`），每角色最多一次。Plus 明确 OOM 时停止并留诊断；不得自动降级或重复付费。冻结的 Standard/Lite 任务仍按原实例与恢复合同续跑。★ 48GB 实测（09-16）：耗时 `t = 19s + 39s × 窗口数`，去 block swap／改 `load_device`／改量化均为噪声 ⇒ **显存升级不等于提速**。
- 双主持用 `submit_all_then_poll`：每次提交前预留预算，取得任务号后先原子写入付费账本，再提交下一角色；两个任务号均持久化后由 RunningHub 云端并行生成。项目状态仍由单线程写入；已有 task ID 只轮询或对账，提交结果不明进入 `ambiguous` 并停止。
- V2 精确帧清单是逐句切点权威，Whisper 仅作诊断；低置信度或 ASR 失败不得开启二次人工切点审核，也不得改写确定性切点；只有清单、输入或外部产物漂移才停止任务。
- 供应商视频的帧数/时长漂移不是 OOM。本地克隆末帧须同时满足：V2 manifest SHA／输入签名／角色音频账本匹配，原片 PTS 从 0 按 1/25 秒连续，缺失不超过 5 个末尾帧且位于最后语音之后，冻结 PCM16 WAV 从最后语音结束到结尾全为零；克隆帧须从静音开始，末尾语音落在该帧开头不得超过 10ms（25FPS 单帧的四分之一），超过即硬失败。以冻结 WAV 为唯一音源重编码；必须保留带 SHA 身份的 provider raw；本地规范化不得增加尝试、预算预留、上传或付费提交。
- 2026-08-27 双角色已用该配置实测并获人工认可：檬檬0.455元、雅雅0.775元，账单约4元/小时，总费用1.23元。
- Standard 24GB 只通过过短样本验收（118 帧 / 0.176 元）⇒ **不可外推**，生产长度（407–1717 帧）早已 OOM，不得据此切回 24GB。
- 每日总预算不超过 5 元；费率异常须停止后续付费提交并展示证据。
- 4:5 数字人不得拉伸；圆形模式先做方形取景再加圆形蒙版，预览与渲染必须一致。
- RunningHub 上传工作流文件名不得超过50字符；交付用用户指定中文工作流名，构建与测试阶段阻断超长名称。
- 旧 LongCat 与早期 InfiniteTalk 256×320/384×480 只留兼容与诊断；新默认 448×560、25FPS，接受 4:5 半身近景与长音频。

## 跨仓研究包消费

- 研究包不进生产队列（消费隔离合同，见 `test_research_pack_cross_repo.py`）；`argument_graph.nodes` 允许为空。
- **消费端校验不得严于冻结合同**：合同的可空/可选字段（`selected_topic|null`、`rights.material_id?`）与条件式事实源（`claim.source_ids` 只在 `confirmed_official`/`confirmed_two_reliable` 时须已核验）不得判输入不合格；编辑层自身要求（必须有选题提案）在 gate 阻断（exit 3）。
- **不得用 claims 回填 `argument_graph.nodes`**：默认适配器恒产 `nodes: []`，其 claims 为 `unverified`＋`hedge`、`fact_sources_present=0`，回填会让未核验结论拿到 `argument_map_ready`。
- **`claim.topic_id` 不守**：合同未要求与选题一致，适配器不写。

## 外站素材复刻

- **素材选择权归项目，不归 copyskill**：其产出只当素材池的一份输入，与 Pexels 地位平等；选区段前必须先看多宫格帧大图，禁止「整条源当一整块素材」。
- **`remake-spec-v1` 是唯一机读口径**（`schemas/remake-spec-v1.json` ＋离线口径层 `backlot/remake_project.py`），帧口径与 `_validated_visual_timeline` 一致。
- **重建必然改变音频混音签名 ⇒ 必须把第一段声音样板置 stale**，否则 `full_preview` 直接 422；资产表只增不删会把画面绑回旧素材。

## 画面与审核

- AI 画面规划器在网络视频与 HyperFrames 间按时长控比例，默认实拍 60%—70%、HyperFrames 30%—40%，静态图片默认不用。
- 视觉批次失败只恢复失败槽位，已完成素材不得重做；HyperFrames 布局检查失败可回退未使用的网络素材。为修复最终比例，经两轮严格语义审查后可启用显式 `contextual_broll`：只允许相关、非误导、全片唯一的环境补画面，并记录拒绝理由与覆盖。
- 官方素材提取已启用：抓原站正文 `og:image`（回退 `twitter:image`/首图）作官方配图，标注 `license="press"` 与署名，沿 research→selection→script→scene 透传；AI 导演在图片槽位优先下载官方配图（失败回落 Pexels），资产标记 provider=`官方媒体`。仅图片槽位生效，视频槽位仍走 Pexels/HyperFrames。
- 每条新闻以 `story_id` 复用右上角固定小标题；HyperFrames 不得重复烘焙。
- 人声增益、BGM 增益与成片响度是三个独立合同，处理顺序固定为 人声增益 → 背景音乐 → 最终 loudnorm。软件级默认值、响度天花板算法与平台端实测结论见 `PRODUCT_RULES.md`，不在本文件重复。
- 已锁定格不被批量操作覆盖；单格替换不影响其他格。
- 先快速生成全片预览，再回问题片段返工。
- 片段工作台的数字人取景编辑器只显示静态、强制静音的预览帧；进入页面、刷新、切换片段或控件重绘都不得自动播放或恢复原声。
- 新项目默认用左上圆形数字人模板：位置 `x=0.04 / y=0.03`、宽度 `0.29`、底部裁切 `0`，圆形取景 `x=0.48 / y=0.38 / zoom=1.15`（2026-08-23 人工调整、全量 15 段确认）。
