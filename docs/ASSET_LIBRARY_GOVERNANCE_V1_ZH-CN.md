# 素材库治理 V1

## 目标

让项目素材从“只登记、难收口”变成可查、可筛、可回收、可恢复的资产库；不以一次性删除换取空间。

## 已实现的操作

1. 进入「素材库」，点击「扫描素材库」。扫描只读，不会移动或删除文件。
2. 系统为每个 `S-xxx` 素材标记状态：
   - **正在使用**：当前片段时间线、当前配音、数字人出镜、关键帧审核、待完成局部任务中的任一项仍引用它。
   - **可清理**：当前没有交付引用，且来源是网络下载、AI 生成或本地生成，文件完整位于项目 `assets/` 目录。
   - **文件缺失 / 仅登记**：需要人工补文件或补路径，系统不会擅自处理。
   - **回收站**：已从 `assets/` 移入本项目 `artifacts/recycle-bin/`，可恢复。
3. 使用「仅看可清理」或「全选可清理」确认范围，再点击「移入回收站」。
4. 如需撤回，在筛选器选择「项目回收站」，点击对应素材的「恢复」。文件会回到它原来的项目路径。

## 安全边界

- 不提供不可恢复的批量删除。
- 人工提供和项目素材库来源默认受保护，不进入“一键全选”。
- 服务端会在执行移动前重新计算引用关系，防止浏览器扫描结果过期后误处理已被采用的素材。
- 只有位于当前项目 `assets/` 内的文件可被批量回收；项目外路径、渲染成片和不完整记录不会被移动。
- 素材的编号、来源、使用历史和回收记录始终保留在工作台状态中。

## 额外治理能力

- **内容级重复识别**：扫描使用 SHA-256 内容哈希识别重复文件，展示重复组，但从不自动删除重复素材。
- **引用说明**：素材台账直接展示它被哪一种当前决策锁定，例如画面区间、当前配音、数字人出镜或关键帧审核。
- **空间统计**：显示可释放文件数与预计释放空间，避免用户只凭名称猜测。

## V1 后续建议

1. 增加“归档项目”策略：把已发布版本的冻结素材整体转入长期归档，而不是与工作中素材混在一起。
2. 增加“素材标签 / 主题 / 镜头类型 / 人物限制”元数据，辅助批量检索和避免重复下载。
3. 为回收站加入可配置保留期与显式的二次确认清空操作；在此之前保持永久可恢复。
