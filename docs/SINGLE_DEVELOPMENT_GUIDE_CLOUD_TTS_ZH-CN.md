# 单次开发指导：云端豆包 TTS 与可切换配音中心

## 1. 本次目标

在不删除、不弱化 Haike Video 本地 Qwen3-TTS 与 faster-whisper 接口的前提下，引入可选的火山引擎豆包语音合成能力，并把“雅雅 / 檬檬”两个云端音色接入配音中心和视频生成工作流。

本轮完成后，用户应能在配音中心选择本地或云端音色、试听并设为默认；无数字人一键预览和双主持数字人流程应冻结并使用所选音色。云端服务不可用时必须明确失败，不得静默换音色、重复付费提交或伪装成本地成功。

## 2. 冻结边界

### 允许修改

- 豆包 TTS 工具、统一 TTS 运行时和相应测试。
- 配音中心后端、页面及相应测试。
- 无数字人配音、数字人驱动音频、双主持长音频中与 TTS 路由直接相关的后端代码。
- 环境变量模板、部署说明、当前交接状态和本指导文档。

### 不修改

- 片段工作台“小标题 / 字幕自由调整”相关前端文件及交互。
- faster-whisper 的识别实现和现有切割策略。
- RunningHub 数字人工作流、预算恢复策略和已验收付费产物。
- 用户本地声纹、参考音频、认证文件、浏览器资料和生成媒体。

### 密钥与付费边界

- API 密钥只从环境变量或 Git 忽略的本地配置读取；禁止写入源码、文档、测试快照、命令行参数、日志、UI 或 Git。
- 音色 ID 通过配置映射，不把云 TTS 固化为唯一实现。
- 真实测试先生成一条约 10--15 秒的短样本；仅复用同一已受理任务轮询，不因超时或状态不明重复提交。
- 在密钥未被安全配置时，只做无付费模拟、静态和回归测试，并把真实验收标为待完成。

## 3. 设计方案

### 3.1 统一音色模型

配音中心向上层暴露统一的音色记录：稳定的 `profile_id`、`provider_id`、显示名称、角色、可用状态和供应商元数据。本地音色继续由 `voicebox_tts` 提供；云端雅雅和檬檬由 `doubao` 提供。

旧项目只保存本地 `profile_id` 的数据必须继续可读。新任务在启动时同时冻结 `provider_id` 和 `profile_id`，避免用户中途修改默认音色影响正在运行的任务。

### 3.2 统一生成入口

建立一个后端统一入口，根据音色记录路由：

1. 本地音色调用现有 Qwen3-TTS / Voicebox 适配层；
2. 云端音色调用豆包 Speech 2.0 异步接口；
3. 下游需要 WAV 时，将云端结果规范化为单声道 PCM WAV，并保留原始时间戳元数据；
4. 返回真实音频时长，继续作为视频时钟和精确帧对齐依据。

### 3.3 配音中心

配音中心展示本地和云端供应商状态，允许：

- 查看雅雅、檬檬及本地音色；
- 生成短试听；
- 将任一可用音色设为默认；
- 清楚区分“本地 / 云端”和不可用原因。

界面不得显示密钥、完整供应商异常载荷或可能包含认证信息的请求头。

### 3.4 工作流接入

- 无数字人一键预览：按任务启动时冻结的音色逐句生成，既有音频时长、字幕、画面和渲染逻辑保持不变。
- 数字人单角色驱动音频：复用统一入口，不改变 RunningHub 提交与恢复语义。
- 双主持：雅雅、檬檬按角色映射到对应云端音色；音频仍串行生成，随后沿用现有精确帧对齐和切割逻辑。

## 4. 开发任务

1. 完善豆包 TTS 工具：请求鉴权、异步轮询、错误脱敏、时间戳和输出元数据测试。
2. 新增统一 TTS 运行时：音色解析、供应商路由、音频格式规范化和真实时长返回。
3. 扩展配音中心数据结构与 API，同时保持旧配置兼容。
4. 扩展配音中心 UI，显示多供应商、多音色和状态反馈。
5. 将无数字人、数字人驱动音频、双主持配音改为统一入口。
6. 更新环境变量模板与部署说明，补充雅雅 / 檬檬的角色音色配置。
7. 运行专项测试、全量回归、安全扫描和一条受控真实短试听。

## 5. 测试计划

### 自动化测试

- 工具层：模拟提交、轮询、成功下载、失败、超时和错误脱敏。
- 配音中心：本地 / 云端目录、默认音色持久化、不可用音色拒绝、云端试听路由。
- 工作流：任务冻结音色；无数字人与数字人路线都调用统一入口；双角色映射不串音。
- 兼容性：旧的本地音色配置和现有测试继续通过。
- 前端：多供应商卡片、状态、按钮禁用和错误信息契约。

### 真实短样本

- 仅在密钥已安全配置且服务可达时执行。
- 选择一个云端音色生成约 10--15 秒中文语音。
- 校验文件可解码、时长大于零、采样信息有效、元数据含任务标识和句级 / 词级时间信息（若服务返回）。
- 不执行整条 120 秒视频，不启动 RunningHub，不扩大付费范围。

## 6. 验收标准

以下条件同时满足才标记本轮完成：

1. 配音中心可同时展示本地 Qwen3-TTS 与云端豆包音色，云端不是唯一实现。
2. 雅雅和檬檬分别映射到独立配置项，选择和默认设置可持久化。
3. 云端试听有持续的生成中状态；成功后可播放，失败后错误可理解且无密钥泄露。
4. 无数字人任务冻结并使用所选音色，实际音频时长继续驱动画面和字幕。
5. 数字人 / 双主持路线能按角色选择正确音色，不重复生成已成功音频，不改变既有精确帧切割。
6. 云端结果保留可用的时间戳元数据；WAV 规范化后可被 FFmpeg / ffprobe 和现有流水线读取。
7. 相关专项测试与全量回归通过；若存在平台或权限导致的未测项，必须如实标记 `partial`，不得宣称真实云端验收完成。
8. Git 差异中不含 API 密钥、本地认证、声纹、私有素材或生成媒体。

## 7. 停止条件

- 云端请求状态不明、供应商已受理但未返回确定终态时，停止自动重提。
- 发现并发窗口修改同一文件或工作区出现无法归属的改动时，停止覆盖并先核对。
- 真实短样本失败两次或出现非预期计费时停止付费测试，保留证据供人工判断。
- 本地回归发现视频主流程退化时，不继续部署或推送。
