# Source and release provenance

Haike Video is an independently branded, modified distribution derived from
[`calesthio/OpenMontage`](https://github.com/calesthio/OpenMontage).

- Upstream base commit: `4eab34c5cfcccaa4f1970554928feccce73ee930`
- Product and repository name: Haike Video (`Haike_video`)
- Release format: curated source snapshot without upstream Git history
- License: GNU Affero General Public License v3.0; see `LICENSE`

The snapshot keeps source, tests, public templates, dependency locks, and
deployment documentation. Credentials, private voice profiles, presenter
images, project media, model caches, rendered outputs, and paid-provider task
artifacts are deliberately excluded.
