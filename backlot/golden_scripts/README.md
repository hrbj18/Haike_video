# 黄金范例库（few-shot）

这个目录存放你**人工确认过、传播效果好的成稿**，作为写稿时的 few-shot 风格范例注入给模型。

## 作用

模型写"相声式双主持口播"之所以"差点意思"，根因之一是风格规则太抽象。把满意的成稿放进来，模型就能照着真实的节奏、口吻和承接方式学，而不是只靠几条文字规则。

## 格式

每个文件是一个 JSON，结构如下：

```json
{
  "title": "这条新闻的小标题（仅用于模型理解上下文）",
  "lines": [
    {"speaker_name": "雅雅", "text": "每日科技快讯来了，……"},
    {"speaker_name": "檬檬", "text": "……"}
  ]
}
```

- `speaker_name` 只能是 `雅雅` 或 `檬檬`。
- `lines` 按真实播出顺序排列，相邻句换角色。
- 只放"节奏与口吻"的范例，**不要求与当天真实新闻对应**——写稿 prompt 已强制"禁止复制范例中的事实、公司、型号、数字"。

## 怎么用

1. 把你用豆包（或任何渠道）写出来、最终满意并发布过的稿子，转成上面的 JSON。
2. 放到本目录，文件名随意（如 `2026-08-24-手机降价.json`）。
3. 每次生成会自动读取本目录最多 3 篇（按文件名字典序）作为范例。

## 维护建议

- 保持 3~8 篇，覆盖不同题材（消费科技、大模型、风险警示、开源项目）。
- 定期替换：用表现最好的新稿换掉最旧的一篇，避免范例过期。
- 不要放单篇超过 12 句的超长稿，范例太长会稀释节奏。
