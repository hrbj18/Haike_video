# 科技快报风格包 V1

这是 OpenMontage 的本地、可版本化科技信息图风格。它将暖纸张、深墨线条、硬阴影、橙绿强调和编辑式大标题转化为可审核的 9:16 动态支持画面。

## 画面合同

1. 所有全屏底色位于 `.clip` 内部，根组合节点不承载背景。
2. 一段画面只使用一种语义配方；不得把所有片段变成同一张卡片网格。
3. 画面正文只承载 `graphic` 角色的短文本；逐句台词属于字幕层，禁止烘焙。
4. `presenter_safe_region` 留给现有数字人层，`caption_safe_region` 留给字幕层；主体内容不得侵入。
5. 节点、连线与标题分阶段进入；整个运动在有限时长内结束，不使用无限循环。

## 竖屏布局

顶部是短标题与分类标签；中部是关系图或信息结构；左上为数字人预留窗；底部为字幕保留区。设计的重点是让用户一眼理解“这一段要表达的关系”，而不是展示一个通用的科技背景。

## 字幕建议

默认沿用用户已有字幕方案。用户显式选择“应用科技快报 V1 推荐字幕”后，才将暖白粗体、深墨描边、两行内、底部居中的建议方案应用到当前或全部片段。
